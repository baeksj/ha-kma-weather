# Brand assets

User provided a KMA sticker/logo image to use as the integration icon.

Recommended exports for Home Assistant-style branding:

- `icon.png`
- `icon@2x.png`
- `logo.png`
- `logo@2x.png`

Current guidance based on the provided image:
- The source image is suitable for square icon usage.
- For `icon*`, crop to the central circular KMA emblem and exclude the lower `기상청` text when possible.
- Prefer transparent PNG exports if possible.
- `logo*` may keep more of the original composition if desired.

This folder is ready for the actual rendered assets.
